WORK TRACKER APP - how to put it online and install it

1. Make a free account on Netlify (netlify.com) or GitHub Pages.
2. Netlify: open "Sites" and drag this whole folder (or the unzipped folder) onto the page. GitHub Pages: upload all files to a new public repository and turn on Pages.
3. Open the link you get on your phone or computer (it must be https).
4. Phone: Chrome menu > "Install app" / "Add to Home screen". iPhone: Safari Share > "Add to Home Screen".
   Desktop: click the install icon in the Chrome or Edge address bar.

Records are saved on each person's own device. Use "Save backup" often.
